# 📊 Bank Loan Applications Dashboard

An interactive Excel dashboard project focused on analyzing bank loan application data to uncover business insights, performance trends, and loan risk indicators.

This project involved cleaning raw data, transforming datasets, creating KPIs, and building a dynamic dashboard for data-driven decision making.

---

## 🚀 Project Overview

The dashboard was created to analyze:
- Loan applications
- Funded amounts
- Loan repayment performance
- Borrower behavior
- Risk distribution
- Geographic and employment-based insights

Using Excel tools like Pivot Tables, Charts, Slicers, and Formulas, I designed a fully interactive reporting dashboard.

---

## 📌 Key KPIs

| KPI | Value |
|------|------|
| Total Loan Applications | 14.4K |
| Total Funded Amount | $169M |
| Total Amount Received | $183.5M |
| Average Interest Rate | 12.30% |
| Average Debt-to-Income Ratio | 13.35% |
| Good Loans | 84% |
| Bad Loans | 16% |

---

## 🧹 Data Cleaning & Transformation

### Tasks Performed:
- Cleaned and structured raw loan data
- Removed inconsistencies and formatting issues
- Created calculated columns using Excel formulas
- Classified loans into:
  - Good Loans
  - Bad Loans
- Prepared data for dashboard visualization

---

## 🎛️ Interactive Dashboard Features

The dashboard includes dynamic slicers for:
- Loan Grade
- Loan Purpose

### Example:
Selecting **“Car”** from the Purpose slicer instantly updates:
- KPIs
- Charts
- Loan trends
- State analysis
- Employment analysis
- Loan status metrics

This makes the dashboard highly interactive and business-focused.

## 💡 Key Insights

- Strong loan demand throughout the year
- 84% of loans are performing successfully
- Debt Consolidation is the most common loan purpose
- 36-month loans are preferred over 60-month loans
- Applicants with 10+ years of employment apply more frequently
